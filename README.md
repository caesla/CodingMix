# SpotifyMix

> Work in progress. Not usable yet.

SpotifyMix watches what you are doing in [Claude Code](https://claude.com/claude-code)
(coding, debugging, planning, reviewing...) and plays fresh Spotify music that fits the
activity, following one rule: **never play a track you listened to or saved in the last 7 days**.

- Requires Spotify Premium and your own (free) Spotify developer app.
- Runs locally as a small background service. No secrets, no telemetry.
- Target platforms: Windows, macOS, Linux.

Design document (Italian): [docs/superpowers/specs/2026-09-30-spotifymix-design.md](docs/superpowers/specs/2026-09-30-spotifymix-design.md)
